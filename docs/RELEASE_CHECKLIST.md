# Release checklist

Проверка проекта перед публичной демонстрацией или выпуском новой версии.

## Репозиторий

- [x] README описывает задачу продукта, архитектуру и локальный запуск.
- [x] Добавлены case study, AI-архитектура и security policy.
- [x] CI проверяет PostgreSQL-схему, бизнес-сценарии, тесты и frontend build.
- [x] Dependabot отслеживает безопасные обновления зависимостей.
- [ ] Добавить чистые скриншоты интерфейса без рамки браузера и персональных данных.

## Демо-данные

- [ ] Использовать отдельные демонстрационные аккаунты трёх ролей.
- [ ] Не публиковать пароли демонстрационных аккаунтов в репозитории.
- [ ] Убедиться, что в базе нет настоящих телефонов, Telegram ID и заметок клиентов.
- [ ] Подготовить будущие слоты, несколько записей и отзывы для показа интерфейсов.

## Функциональная проверка

- [ ] Клиент видит только мастеров выбранной услуги и реальные свободные слоты.
- [ ] Создание, перенос и отмена записи работают без конфликта времени.
- [ ] Клиент видит только собственные записи.
- [ ] Мастер видит только своё расписание, может отметить визит и создать перерыв.
- [ ] Администратор управляет услугами, мастерами, расписанием и отзывами.
- [ ] AI не выдумывает услуги, мастеров и слоты; fallback работает без внешней модели.
- [ ] Telegram-привязка, напоминание и запрос оценки проходят полный цикл.

## Production

- [ ] `/api/health` отвечает успешно.
- [ ] Production и Preview подключены к нужной базе данных.
- [ ] Frontend, API, Telegram webhook и scheduled reminders используют публичный HTTPS-домен.
- [ ] Секреты присутствуют только в environment variables хостинга.
- [ ] CORS содержит только разрешённые origins.
- [ ] Проверены мобильные Safari/Chrome и desktop Chrome/Firefox.
- [ ] В логах нет внутренних ошибок и персональных данных.

## Перед показом

- [ ] Открыть сайт и GitHub в приватной вкладке.
- [ ] Проверить публичные ссылки и CI последнего коммита.
- [ ] Пройти сценарий из [`DEMO_SCRIPT.md`](DEMO_SCRIPT.md).
- [ ] Не открывать `.env`, настройки Vercel/Neon и реальные данные клиентов.
